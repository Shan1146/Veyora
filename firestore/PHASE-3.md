# VEYORA Phase 3 — Media Discovery

Includes:
- Jikan anime search
- TMDB movie and TV search
- Unified search page
- Anime/movie/TV filters
- Title details page
- Poster and backdrop rendering

## Setup

1. Put your TMDB Bearer token in `js/api/tmdb.js`.
2. Keep the token out of public Git repositories.
3. Serve the project through a local web server (ES modules and API requests should not be opened with `file://`).

Library saving is intentionally reserved for Phase 4.
